# Trần Đình Trọng · Portfolio

Portfolio website (Photographer & Art Director, TP. Hồ Chí Minh). Static site: `index.html` + `img/` + `fonts/`, no build step.

## Chạy thử
Mở `index.html` bằng trình duyệt, hoặc chạy `python3 -m http.server` rồi vào http://localhost:8000.

## Đưa lên GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.

## Lưu ý
- Font SVN-Gilroy trong `fonts/` là font có bản quyền: kiểm tra giấy phép trước khi để repo công khai.
